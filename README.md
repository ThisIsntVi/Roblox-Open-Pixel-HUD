# Roblox Open Pixel HUD

A clean, professionally scaled, and unscripted User Interface HUD designed for Roblox developers. This asset was originally released to the community via my developer portfolio and has been migrated to GitHub to ensure long-term accessibility, community contributions, and version control.

##Features
* **Pixel-Perfect Aesthetic:** Clean UI components optimized for retro, simulator, or pixel-art themed Roblox games.
* **Fully Responsive UI:** Configured natively using **Scale** rather than Offset, ensuring flawless display across PC, Console, and Mobile viewports.
* **Clean Hierarchy:** Explicitly named and organized Explorer hierarchy, making it seamless for scripters to hook up backend code.

## 🛠️ Installation Instructions
1. Download the `.rbxm` file from this repository.
2. Open your project in **Roblox Studio**.
3. Right-click on `StarterGui` in the Explorer panel.
4. Select **Insert from File...** and choose the downloaded file.
